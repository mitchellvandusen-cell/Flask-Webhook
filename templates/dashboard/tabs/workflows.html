InsuranceGrokBot Re-Engage Workflow
1
Create a new workflow from scratch in your Lead Connector account.
2
Assign the trigger to "Tag Added".
3
Add a Wait delay (1 or 2 minutes).
4
Select the "+" button, go to the "Apps" tab, scroll to InsuranceGrokBot, and select the action.
5
Add an "If/Else" condition. For the IF: check if contact has an "appointment booked" tag, then end the workflow.
6
Add a Wait step (1 day).
7
Add a "Go-To" and select above the first wait, under the trigger. This creates the re-engagement loop.

Smart Tag Intelligence

Tags tell the AI what kind of lead it's talking to. The AI cross-references your tags with the contact's import date to verify accuracy. A "fresh" tag on a 90-day-old contact gets overridden automatically.

fresh
Speed-to-lead. They just requested info. The AI knows they're expecting a response and adjusts its tone accordingly.
Verified by date? Yes
If tag + import ≤ 3 days Confirmed fresh
If tag + import 31-90 days Overridden to aged
If tag + import 90+ days Overridden to very old
aged
Purchased aged lead, 30+ days old. The AI knows they may not remember filling out any form and adjusts expectations.
Verified by date? Yes
If tag + import ≤ 7 days Recently purchased aged
If tag + import 90+ days Upgraded to very old
re-engage
Dormant lead you're circling back to. Always trusted regardless of date because this is an explicit agent action.
Verified by date? No (always trusted)
Priority Highest (overrides other tags)
Date Intelligence

The AI automatically reads the contact's Date Added or Date Created from your CRM. Even without tags, it can infer lead freshness:

0-3 days Inferred fresh
4-30 days Ambiguous
31-90 days Inferred aged
90+ days Very old
Lead Vendor (Custom Field)

If you have a custom field in your CRM named any of the following, the AI will automatically extract the lead vendor and include it in the contact's profile:

lead_vendor lead_source lead_provider vendor

This helps the AI understand where the lead came from (QuoteWizard, MediaAlpha, etc.) and adjust its approach.

Multiple Tags

If a contact has conflicting tags (e.g. both "fresh" and "aged"), the AI uses this priority: re-engage wins over fresh, which wins over aged. The import date is then used to verify whichever tag won. Stale tags get overridden automatically.
