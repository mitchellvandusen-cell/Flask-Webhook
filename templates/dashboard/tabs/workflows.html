Set up automation in your Lead Connector account

InsuranceGrokBot Re-Engage Workflow
1
Create a new workflow from scratch in your Lead Connector account.
2
Assign the trigger to "Tag Added".
3
Add a Wait delay (1 or 2 minutes).
4
Select the "+" button, go to the "Apps" tab, scroll to InsuranceGrokBot, and select the action.
5
Add an "If/Else" condition. For the IF: check if contact has an "appointment booked" tag, then end the workflow.
6
Add a Wait step (1 day).
7
Add a "Go-To" and select above the first wait, under the trigger. This creates the re-engagement loop.
InsuranceGrokBot SMS Reply Workflow
1
Set the trigger to "SMS Received" by contact with tag.
2
Add a Wait step.
3
Select the "+" button, go to "Apps", and add the InsuranceGrokBot action.
